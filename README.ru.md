<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/screen-resolution-finder/raw/main/favicon/favicon.svg" width="40"/> Определитель разрешения экрана</h1>

<p align="center">
  Адаптивное веб-приложение, которое отображает ширину и высоту вашего экрана, предоставляя быстрый и точный способ проверки размеров области просмотра.
